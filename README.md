# Universe

Simulación física completa del universo, desde partículas fundamentales hasta la vida emergente, utilizando Python 3.12 y CUDA.

Este proyecto está orientado a representar la realidad con máxima fidelidad científica, modularidad y escalabilidad. Incluye soporte para computación en GPU con CuPy, simulaciones cuánticas, nucleares y biológicas futuras.

## Requisitos

- Python 3.12
- CUDA Toolkit 12.x
- NVIDIA GPU compatible
- CuPy (`cupy-cuda12x`)
- PyQt5 para visualización avanzada
